# Signalement d'un problème de confidentialité

Cette documentation ne contient aucun composant exécutable du projet audité.
Si une information potentiellement confidentielle est néanmoins identifiée,
ne pas la republier ni l'exploiter.

Contacter directement l'auteur par un canal privé en indiquant :

- le fichier et la section concernés ;
- la nature de l'information exposée ;
- la raison pour laquelle elle devrait être retirée.

Aucun détail sensible ne doit être ajouté dans une issue publique.
